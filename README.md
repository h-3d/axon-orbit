# axon-orbit

Decentralized 3D space shooter built with [Three.js](https://threejs.org/) & [Trystero](https://oxism.com/trystero/). 🚀

🎮 [Play the Live Demo](https://h-3d.github.io/axon-orbit/)

## Features

- Browser-based 3D game
- Online multiplayer using peer-to-peer networking
- 6DOF first-person flight controls in all directions
- Lasers that can be fired and seen in real time
- Health and damage system with collision-based hit detection, and automatic respawn
- Procedural starfield using thousands of instanced stars
- Protected safe zone outside the world bounds
- On-screen HUD showing health and live XYZ coordinates

## Controls

- Direction: `Mouse` or `Arrows`
- Thrust: `WASD`
- Altitude: `R` / `F`
- Roll: `Q` / `E`
- Shoot: `Space`
